## 2026-10-09 — player request run: Paul Gilbert rebuild (manual fire, via the development thread)
- Player request (from Chris via the development thread, delivered with the run): rebuild the Paul Gilbert course on researched, concept-first paths, then switch other artists to `PU`. Done first; the normal depth/artist/discovery steps were covered by it (5 paths completed; one queue topic considered and recorded).
- Research confirmed his defining techniques: strict alternate picking with a small, slanted wrist motion and attention to how the pick crosses strings (Guitar World "Intense Rock" analysis), three-notes-per-string scale picking as his favourite exercise, string skipping into wide triad arpeggios (Guitar Player lesson), the six-note pentatonic lick, and pentatonic sequences and stretched shapes (Premier Guitar cram session, Troy Grady forum discussion of the "Paul Gilbert lick"). Odd groupings against the beat were considered as an extra topic but no source singled them out as his; fives against 16ths are inside pent6s and alternatePicking, and a general rhythm-grouping path is now in the Discovered queue.
- **New, complete: `alternatePicking`** (3/6 · 4/8 · 3/6 · 3/6). Model: the stroke rule, `changes()` counting inside vs outside string changes, the seven 3nps positions (`position()` from economyPicking), sequences; composer `ap(c, spec)`. Foundations: one string four strokes per note, the four-finger pattern (fingering by level), all-outside 3+3 cells, starting on an upstroke, a palm-muted riff. Intermediate: 3nps positions 1 and 5, all-inside 2-3-1 cells, 3rds (mixed changes), groups of 3 and 4, a 16th-note riff. Advanced: speed bursts, accented threes in 16ths, string skipping on G/high e, four keys, harmonic-minor pedal lines. Mastery: sixes and fours at tempo, random key/scale/position, capstone study.
- **Completed: `pgSix`** (3/6 each stage). Model: the cell on any box string pair (L0 L1 H0 H1 H0 L1 = all inside changes; its mirror = all outside); composer `six(c, spec)` over direction × pairs × boxes × keys × note value. Kept ids `pg-six-note`, `pg-six-across`.
- **Completed: `pent6s`** (now "Pentatonic in sixes and other sequences"; 3/6 · 4/7 · 3/6 · 3/6). Model: the grouping rule `grouped(list, n, dir)` on any box or the diagonal; composer `seqRun`. Kept id `pg-pent-6s` (the pentatonic path still uses it).
- **Completed: `stretchPent`** (3/6 · 4/7 · 3/6 · 3/6). Model: five 3nps pentatonic shapes (one per degree) on the top or bottom three strings, plus the full six-string diagonal, which only fits low on the neck, so `fullShape()` picks the shape that fits in each key. Kept id `pg-stretch-pent`.
- **Completed: `skipArps`** (3/6 each stage). Model: `skipCell(chord, strings, inversion, near)` builds any triad as two chord tones per string on adjacent, skipped (4–2, 5–3, 3–1) or three-string (5–3–1, two-octave) sets; voice leading picks the nearest inversion. Kept id `pg-skip-amfcg`.
- **New shared helper in lib.js: `targetGuide(c, {prog, scale, name})`**, an improvisation lesson like the `targetSolo` atom but with a tab of one landing chord tone per bar, so improvisation lessons open in the tab player. Used for every solo lesson in the five rebuilt paths and the Gilbert page.
